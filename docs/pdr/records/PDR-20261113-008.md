# 未適用だった Issue 通知のマイグレーションを 1 本へ統合する

## 決定

PR #50 の未適用だった 0006 / 0007 を、最終形のテーブルとトリガーを作る 0006 の 1 本へ統合する。スナップショットとジャーナルも最終形へ揃える。

## 理由

統合を判断した時点で対象のマイグレーションは未適用と確認されていたため、中間スキーマを経由する互換性維持が不要であり、最終形への作成と作り直しを残す必要がない。

## 範囲と例外

PR #50 に対する当時の指示に限定する。適用済みのマイグレーションを再編集する一般的な許可ではない。その後の本番適用状況は別途確認する。

## 選択肢と影響

適用済み環境がある場合は追加マイグレーションで既存データを扱う必要があり、この統合の前提を満たさない。
