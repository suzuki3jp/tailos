# Claude Code は Agent SDK から実行する

## 決定

Runner は Agent SDK（`@anthropic-ai/claude-agent-sdk`）の `query()` で Claude Code を実行する。Claude Code CLI を Runner が直接起動して出力を読む方式は採らない。

## 理由

Claude Code をプログラムから操作するには、CLI を子プロセスとして起動して行単位の JSON を読む方法と、同じ CLI を内部で起動する Agent SDK を使う方法がある。SDK を使うと次のことをコードで扱える。

- Tailos の GitHub 参照ツールを Runner プロセス内の関数として提供できる。checkout token を Claude Code のプロセスへ渡さずに済む。
- ツール呼び出しの直前に Runner のコードで検査し、作業ディレクトリの外にあるファイルの読み書きを拒否できる。Claude Code の OS レベルの隔離は Bash にしか効かないため、ファイル操作のツールにはこの検査が必要になる。
- メッセージ、結果、中断、会話の再開を型付きの API で扱える。

CLI を直接起動する場合は、メッセージの検証、ツール用の MCP エンドポイント、プロセス管理を Tailos が持つことになる。

## 範囲と例外

Runner の Claude 用 `AgentAdapter` に適用する。Codex は従来どおり `codex app-server` を起動する。SDK の import、メッセージから共通の記録への変換、ツール定義、検査は Claude 用の Adapter に閉じ、API と Runner の共有契約には SDK の型を出さない。

採択時点では未実装。Cloudflare Containers 上で SDK が長期 OAuth トークンで認証できること、隔離が起動できることは実装前に確かめる。確かめた結果この方式が成り立たない場合は、後継の記録で見直す。

## 選択肢と影響

SDK は Claude Code のネイティブバイナリを optional dependency として持つため、Runner の単一バンドルには入らない。Runner イメージに別途導入し、SDK を使わないジョブがバンドル単体で動く状態を保つ必要がある。ツール定義は Zod のスキーマを要求するので、Valibot に統一している Runner に Zod が一箇所だけ入る。

SDK のドキュメントは SDK で作る Agent に API キーでの認証を案内している。長期 OAuth トークンとの組み合わせは `agent.claude.authentication` の範囲に限って使う。
