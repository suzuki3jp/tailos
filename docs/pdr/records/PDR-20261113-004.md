# 返答上限 8,000 の当初の選定根拠は未確認

## 決定

観測: 返答本文に 8,000 の上限があり、JavaScript の文字列長と共有スキーマで検証している。当初なぜ 8,000 を選んだかは未確認。値の妥当性を合意した記録ではない。

## 理由

通信・保存・画面表示の負荷を抑える意図は考えられるが、8,000 という値の選定理由は確認できていない。推測を人間が承認した理由に変換しないため、未確認のまま残す。

## 範囲と例外

現在のコードから数値や検証方法を確認する際の手掛かり。採択済みの要約方針とは独立した論点であり、この記録を理由に 8,000 が最適だと判断しない。
