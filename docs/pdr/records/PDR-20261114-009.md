# 対象リポジトリの CLAUDE.md と skills は読み込み、設定・hook・MCP は読み込まない

## 決定

Claude Code を実行するとき、対象リポジトリの `CLAUDE.md` と `.claude/skills` の skills を Claude Code に読み込ませる。`CLAUDE.md` がなく `AGENTS.md` があるリポジトリでは `AGENTS.md` を同じように読み込ませる。

対象リポジトリとユーザー領域の設定ファイル、hook、MCP サーバー定義は読み込まない。skill が定義する hook と、skill の本文に埋め込まれて読み込み時に実行されるコマンドも実行しない。

読み込む内容は、チェックアウトした基準コミットの状態で確定する。Agent が Run の途中で書き換えた `CLAUDE.md` や skills は、同じ Run の中で Claude Code を起動し直しても反映しない。

## 理由

`CLAUDE.md` と skills はリポジトリの作業規約と手順であり、Agent がそのリポジトリで正しく作業するために必要になる。skill の手順が呼び出すスクリプトは Bash から実行されるので、Claude Code の OS レベルの隔離の中で動く。

設定ファイルの hook と MCP サーバーは事情が異なる。これらは Claude Code の子プロセスとして隔離の外で動き、Claude のトークンとコンテナのネットワークを使える。対話なしの実行では、対象リポジトリの `.claude/settings.json` と `.mcp.json` が確認なしで有効になる。読み込みを許すと、リポジトリに書かれたコマンドが隔離なしで実行される。skill が定義する hook と読み込み時に実行されるコマンドも Bash ツールを通らないので、同じ理由で止める。

Agent SDK は `CLAUDE.md` と skills を設定ファイルや hook と同じ単位で読み込み、その中から一部だけを選ぶ指定を持たない。そのため SDK の読み込みには頼らず、Tailos が対象リポジトリから `CLAUDE.md` と skills だけを取り出して Claude Code に渡す。

基準コミットの状態で確定するのは、Agent が作業中に書いた内容が、起動し直した Claude Code への指示になる経路を作らないためである。

## 範囲と例外

Claude Code で実行するすべての Run に、mode を問わず適用する。Tailos が Runner のコードから渡す設定、検査、ツールは対象外で、引き続き使う。

読み込むのはリポジトリ直下の `CLAUDE.md`（なければ `AGENTS.md`）と `.claude/skills` である。`.claude/skills` がリポジトリ内の別のディレクトリへのリンクであれば、その先を読む。リポジトリの外を指すリンクは読まない。

サブディレクトリごとの `CLAUDE.md`、`.claude/rules`、コマンド定義、サブエージェント定義は読み込まない。Agent がこれらを通常のファイルとして読むことは妨げない。

`CLAUDE.md` と skills の内容は Agent への入力として扱われるだけで、Tailos が与えた mode、ツール、隔離の設定を変える手段にはならない。skill が宣言するツールの事前許可は適用しない。

## 選択肢と影響

対象リポジトリが用意した hook、MCP サーバー、サブディレクトリごとの `CLAUDE.md` の自動適用は使えない。hook や読み込み時のコマンドに依存する skill は、手元の Claude Code と同じようには動かない。

リポジトリの設定を SDK にすべて読み込ませ、危険な項目だけを除く方法は採らない。除外漏れがそのまま隔離外のコマンド実行につながる。

`CLAUDE.md` も skills も読み込ませず、補足指示で Agent にファイルとして読ませる方法も採らない。skills は Agent が存在に気づかなければ使われず、リポジトリが用意した手順が生かされない。
