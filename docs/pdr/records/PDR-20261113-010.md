# 通知の通算 20 回での打ち切りはプロダクト上の個別承認が未確認

## 決定

観測: PR #50 では、一時障害が起きた際に通算 attempts が 20 以上なら permanent 扱いで停止する。attempts は受付・終了の表示状態とレート制限の試行でも共有される。この回数と集計範囲に対する人間の個別承認は未確認。

## 理由

恒久的な失敗で再送を続ける点へのレビュー対応として Agent が追加した。無制限の再送を避ける意図は説明されたが、20 回の選定と状態間での共有を人間が判断した根拠はない。

## 範囲と例外

PR #50 の実装とレビューに関する観測。コードレビューで後続対応可とされたことを、望ましいプロダクト仕様の承認とみなさない。

## 選択肢と影響

受付時に多く試行すると完了通知の再送余地が少なくなる。状態別の回数・一時障害別の回数・運用による再送の扱いを再検討する。

## 未決事項

人間の承認・選定根拠を確認する。確認できるまでは採択済みの方針として適用しない。
