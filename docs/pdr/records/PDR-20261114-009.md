# 対象リポジトリの Claude Code 設定は読み込み、隔離の境界は Run のコンテナに置く

## 決定

Claude Code を実行するとき、対象リポジトリの Claude Code 設定を読み込む。`CLAUDE.md`、`.claude/rules`、skills、コマンド定義、サブエージェント定義、`.claude/settings.json` とそこに書かれた hook が有効になる。

対象リポジトリの内容に対する隔離の境界は、Run ごとの Cloudflare コンテナとする。Claude Code の OS レベルの隔離は Bash のコマンドに適用し続けるが、対象リポジトリが設定で用意したコマンドを止める境界としては扱わない。

ユーザー領域の設定と、対象リポジトリの `.mcp.json` が定義する MCP サーバーは読み込まない。

## 理由

`CLAUDE.md` と skills はリポジトリの作業規約と手順であり、Agent がそのリポジトリで正しく作業するために必要になる。Agent SDK はこれらを設定ファイルや hook と同じ単位で読み込み、一部だけを選ぶ指定を持たない。Tailos が `CLAUDE.md` と skills だけを取り出して渡す方法は、取り出しと無効化の仕組みを Tailos が持つことになり、手元の Claude Code との挙動の差も残る。

設定ファイルの hook は Claude Code の子プロセスとして Claude Code の隔離の外で動く。それでも Run は Run ごとのコンテナの中で実行され、コンテナは Run の終了とともに破棄される。リポジトリが用意したコマンドが届く範囲はそのコンテナに限られるので、Claude Code の隔離の外で動くことは受け入れる。

## 範囲と例外

Claude Code で実行するすべての Run に、mode を問わず適用する。読み込むのは対象リポジトリの設定だけで、Run の途中で Agent が書き換えた設定が、同じ Run の中で起動し直した Claude Code に読まれることも受け入れる。

Tailos が Runner のコードから渡す mode、ツール、権限、隔離の指定は引き続き渡す。ただし対象リポジトリの設定がこれらを緩められるかどうかは確認できておらず、緩められないことを前提にしない。plan mode で Agent にコマンドを渡さない判断は Tailos が Agent に渡すツールについてのもので、対象リポジトリの hook が plan mode で動くことは妨げない。

コンテナの中には Claude のトークン、公開用のリース、診断の送信先の Bearer がある。hook はこれらと同じコンテナで、ネットワークの制限を受けずに動く。対象リポジトリに書き込める人と、Agent に設定ファイルを書かせられる入力は、これらを読み出して外部へ送るコマンドを実行させられる。対象リポジトリへの書き込み権限を持つ人は、接続した人の Claude のトークンに届く立場として扱う。

## 選択肢と影響

設定を読み込まず、Tailos が `CLAUDE.md` と skills だけを取り出して渡す方法は採らない。hook を含む設定全体を止められる一方、リポジトリが用意した設定の一部しか生かせない。

Codex は対象リポジトリを信頼しない設定で実行し、リポジトリの設定ファイルと hook を読まない。Claude Code のほうがリポジトリの設定に広く従うことになり、同じリポジトリでも Agent によって実行されるコマンドが異なる。

対象リポジトリの MCP サーバーは、`CLAUDE.md` と skills の読み込みに伴って有効になるものではないので、今回は読み込まない。必要になった段階で別の記録として判断する。
