# PDR は Markdown を正本とし検索 CLI から段階的に取得する

## 決定

独立して議論・変更できる論点ごとに Markdown の PDR を Git 管理する。Agent の検索入口は CLI とし、SQLite の索引は正本から再生成する Git 管理外のキャッシュにする。候補カード、決定と適用範囲、理由の順に必要な部分を取得する。人間は Markdown と自動生成一覧から閲覧できる。

## 理由

プロダクト判断の理由をコードとともにレビューできる形で残し、大量の記録を毎回 Agent のコンテキストへ読み込むことを避けるため。検索用データの消失で意思決定そのものが失われないようにする。

## 範囲と例外

Tailos の PDR を対象とする。SQLite や一覧は正本ではない。候補の抜粋・ページングは省略と続きを明示する。検索結果ゼロは決定が存在しない証拠ではない。

## 選択肢と影響

巨大な一覧の常時読み込みはトークン消費が増える。SQLite を正本またはコミット対象にすると差分レビュー・同時編集・整合性管理が難しい。意味検索は、実際の検索漏れを評価して必要になってから追加する。
