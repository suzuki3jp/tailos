# 対象リポジトリの Claude Code 設定は読み込まず、指示ファイルは Agent に読ませる

## 決定

Claude Code を実行するとき、対象リポジトリとユーザー領域の設定ファイル、hook、MCP サーバー定義、skills を読み込まない。`CLAUDE.md` と `AGENTS.md` は Tailos の補足指示で「あれば最初に読んで従う」と伝え、Agent 自身にファイルとして読ませる。

## 理由

Claude Code は Bash のコマンドだけを OS レベルで隔離する。設定ファイルの hook と MCP サーバーは Claude Code の子プロセスとして隔離の外で動き、Claude のトークンとコンテナのネットワークを使える。対話なしの実行では、対象リポジトリの `.claude/settings.json` と `.mcp.json` が確認なしで有効になる。

読み込みを許すと、リポジトリに書かれたコマンドが隔離なしで実行される。Agent が作業中に書き換えた設定が、同じ Run の中で起動し直した Claude Code に読まれる経路もできる。Codex で対象リポジトリを信頼しない設定にしているのと同じ扱いにする。

設定の読み込みを止めると `CLAUDE.md` の自動読み込みも止まる。リポジトリの作業規約は Agent に必要なので、通常のファイルとして読ませる。

## 範囲と例外

Claude Code で実行するすべての Run に、mode を問わず適用する。Tailos が Runner のコードから渡す設定、検査、ツールは対象外で、引き続き使う。

指示ファイルの内容は Agent への入力として扱われるだけで、Tailos が与えた mode、ツール、隔離の設定を変える手段にはならない。

## 選択肢と影響

対象リポジトリが用意した hook、MCP サーバー、skills、サブディレクトリごとの `CLAUDE.md` の自動適用は使えなくなる。手元の Claude Code と Tailos 上の Claude Code で挙動が異なる場合がある。

リポジトリの設定を読み込んだうえで危険な項目だけを除く方法は、除外漏れがそのまま隔離外のコマンド実行につながるため採らない。
