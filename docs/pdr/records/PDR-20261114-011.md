# Claude トークンの期限切れは 30 日前から接続画面で知らせる

## 決定

接続画面は、Claude のトークンを保存した日と、保存から 365 日後の日付を有効期限の目安として常に表示する。目安の 30 日前から「まもなく期限が切れる」と警告し、目安を過ぎたら「期限が切れている可能性がある」と警告する。どちらの警告も、接続を解除してトークンを発行し直すよう案内する。

## 理由

`claude setup-token` の長期 OAuth トークンは有効期間が 1 年で、更新できない。期限が切れると Run が失敗して初めて分かるので、その前に利用者が発行し直せるようにする。

30 日あれば、接続画面をたまにしか開かない利用者でも期限の前に気づける見込みがある。期間をこれより長くすると、対応の要らない時期から警告が出続ける。

## 範囲と例外

Claude 接続の表示にだけ適用する。警告は表示だけで、接続の状態は変えない。目安を過ぎても接続済みのままにし、Run も起動できる。

Tailos が知っているのはトークンを保存した時刻で、発行した時刻ではない。発行から時間を置いて保存したトークンは、目安より早く切れる。途中で失効したトークンも検知しない。

通知は接続画面の表示だけで、メールや Issue へのコメントでは知らせない。

## 選択肢と影響

- 14 日前から: 警告の期間が短く、その間に接続画面を開かないと見落とす。
- 60 日前から: 対応を急がない時期から警告が出る。
