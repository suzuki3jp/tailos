# 決定内容を表すタイトル

## 決定

何を選ぶか。提案中は決定案、未確認の記録は観測であることを明示する。

## 理由

解決する課題、判断の前提となる事実・制約、なぜこの選択が妥当かを本文で説明する。別資料の参照を前提にしない。「指示されたから」やリンクだけで済ませず、由来が分からなければ未確認と明記する。

## 範囲と例外

誰に・どの条件で適用するか。数値の単位・既定値・失敗時の挙動も必要に応じて示す。

## 選択肢と影響

他の案を採用しない理由と、選んだ案の不利益。小さな判断なら短くてよい。
