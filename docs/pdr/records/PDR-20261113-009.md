# 通知 GIF の背景色を favicon の背景色と揃える

## 決定

Issue 通知のローディング GIF は、使用する favicon の背景色に合わせ、回転するアイコンの四角い背景が目立たないようにする。

## 理由

GIF とアイコンの背景色が異なると、回転する四角い境界が目立ち、読み込み表示の見た目を損なうため。

## 範囲と例外

通知のローディング GIF に関する判断。今回の favicon では #f6f3ee だったが、その色を将来のブランド変更後も固定する判断ではない。

## 選択肢と影響

背景色を別々に固定すると不一致が再発する。現在の生成スクリプトは favicon の色を取得する実装だが、取得方法そのものを人間が指定したわけではない。
