# Claude Code の plan mode ではコマンドを実行させない

## 決定

Claude Code で `plan` の Run を実行するときは、ファイルの読み取り・検索と Tailos の GitHub 参照ツールだけを渡す。Bash、ファイルの編集・書き込みは渡さない。

## 理由

plan mode は調査して計画を返すだけで、作業ディレクトリを変更しない。Codex ではコマンドを読み取り専用の隔離の中で実行させてこれを保証している。Claude Code の隔離は書き込み先を許可する形で設定するもので、作業ディレクトリを含めて一切書き込めない状態を同じ確かさで作れるかは確認できていない。コマンドを渡さなければ、隔離の設定に頼らずに変更なしを保証できる。

## 範囲と例外

Claude Code の `plan` に適用する。`implement` では Bash を隔離の中で使える。Codex の plan mode は従来どおりコマンドを実行できる。

## 選択肢と影響

Claude Code の plan では、`git log` などの履歴の確認、依存関係の状態確認、既存テストの実行結果を計画の根拠に使えない。同じ依頼でも Codex と Claude で計画の根拠に差が出る場合がある。

読み取り専用の隔離を確かめたうえでコマンドを許す方式は、確認が済んだ段階で後継の記録として検討できる。
